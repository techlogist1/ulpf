# PROVENANCE — corpus/real/fortinet_fortigate (label: web-cisco-fortinet)

`parsers/fortinet_fortigate.toml` matches on `contains = ["devname=", "logid="]` and parses
the FortiOS 6.x/7.x default `key=value` syslog body. Cleanly-licensed *bulk* real captures of
this exact format were not found in the time box (every promising repo was either unlicensed,
Elastic-2.0, or turned out on inspection to be a different vendor's format mislabeled). This
directory is thin (5 lines total) and that is reported honestly.

current parser doesn't claim to cover (it's documented as FortiOS 6.x/7.x only).
